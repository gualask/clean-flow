# String Boundaries

Build this table from the repository. One row for every name that crosses a boundary as a string — an event, a command, a message type, a job name, a route, a container token — wherever the two sides are held together by convention and not by an import.

| name | consumer file:line | producer file:line |

Fill every cell by reading the source. An empty producer cell, or an empty consumer cell, is a finding: report it as such.
