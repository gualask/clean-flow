# cf-todo

Runtime: [SKILL.md](../../skills/cf-todo/SKILL.md).

## Basis

- **Every task has a done criterion; ask when it is missing.** Wake, [INVEST in Good Stories, and SMART Tasks](https://xp123.com/invest-in-good-stories-and-smart-tasks/) (2003): "The key measure is, “can we mark it as done?”"
- **Durable rationale goes to an owning doc, not the todo file.** Nygard, [Documenting Architecture Decisions](https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions): "We will keep a collection of records for "architecturally significant" decisions".

Kept on the pack's own runs or on the user's decision: one ordered file; GFM checkboxes; recording only what the session produced; the default path and extending an existing file; the docs language; the two sections; checking tasks in place and the rollover rule; routing an open question to `cf-mr-wolf`; staying out of `.cflow/`.
